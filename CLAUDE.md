## Project Overview

ERGM.jl is a Julia port of the R `ergm` package (from StatNet) for fitting, simulating, and diagnosing Exponential-Family Random Graph Models. It provides MPLE and MCMLE estimation (including missing-data maximum likelihood), MCMC network simulation, and goodness-of-fit diagnostics. It is the core of the ERGM bundle: ERGMCount, ERGMEgo, ERGMMulti, ERGMRank, ERGMUserterms and TERGM depend on it and build on the internals named below.

## Architecture

**User terms are probed, not trusted** (`_check_declared_independence`, called by the `ERGMModel` constructor only — NOT by the extension API's `validate_formula`, because TERGM's temporal terms have no two-argument change statistic): a term whose type is defined outside ERGM (an `Offset` of one included), that declares `is_dyad_dependent == false` and reads no edge attribute, has its change statistic evaluated for ~25 dyads on the observed network, the empty network and a ring-wired one; any difference is an `ArgumentError` naming the term and the dyad. Built-in terms are never probed. **The MPLE Newton start with an offset is reached by continuation** (`_offset_start`: the offset switched on in eight warm-started steps, silent), because from zero a large finite offset saturates the probabilities and Newton ran to a flat asymptote.

**Type hierarchy** (`src/terms/base.jl`): `AbstractERGMTerm` is the root, with subtypes `StructuralTerm`, `NodalTerm`, `DyadicTerm`, and `ConstraintTerm` (an unexported placeholder; constraints are refused, see below). Each term must implement `compute(term, net) -> Float64` and `change_stat(term, net, i, j) -> Float64`. The error-throwing fallbacks are typed on the abstract term ONLY (`change_stat(::AbstractERGMTerm, net, i, j)`, no `::Int`), so a user method `change_stat(::MyTerm, net, i, j)` without annotations is strictly more specific and never ambiguous (pinned by the "unannotated user term" testset, which fits one end to end); they throw an `ArgumentError` naming the method to define. **Terms compare structurally**: `==`/`hash` on `AbstractERGMTerm` compare the fields of two terms of the same type (one rule for every term, built-in or third-party; the old per-type `Degree` methods are gone). Further statnet terms live in `src/terms/extended.jl` (included after `materialize.jl`): `Concurrent`, `GWNSP` (= GWDSP − GWESP per type), `ESP(k; type)` (statnet `esp`/`desp`: ties with exactly k shared partners; written from R's documented definition, no ergm source consulted; GWESP's shared-partner code with the weight kernel `_ESPKernel` — w(s) = 1[s = k] — so every type is `GWESP`'s `:OTP`/`:ITP`/`:OSP`/`:ISP`, `:RTP`/`:union` refused; `ESP(0:2)` expands per count in `materialize` like `Degree(0:2)`; labels `esp<k>` / directed `esp.<type><k>`; range `(0, Inf)`, R's `minval`; pinned by section (i) of `ergm_terms.toml` — summary, labels and an `edges + esp(0:1)` MPLE — brute force for every type and the 0-B allocation sets), `DegRange`/`IDegRange`/`ODegRange`, `MeanDeg`, `Density`, `Sender`/`Receiver` (expand per vertex, base = vertex 1) and `TriadCensus` (expands per type; `public`, NOT exported — Siena.jl exports a GOF `TriadCensus`, and two exports would leave the name undefined for `using ERGM, Siena`), all pinned against R's `summary()` (section (h) of `ergm_terms.toml`) and brute force. **`Offset(term, coef)`** (statnet `offset()`, also in `extended.jl`) wraps a term whose coefficient is fixed: `materialize` expands it per statistic, `_offset_info(model)` gives the mask and values; the MPLE (`_mple_fit_offsets` → `_offset_design`) passes finite offsets as the shared kernel's linear-predictor `offset=` (a keyword of the extension API's `mple_fit_design`) and DROPS the dyads an infinite offset fixes — FORBIDDEN where its contribution to the log-odds is −∞, FORCED where it is +∞ — refusing an observed network that violates the constraint (probability 0) or offsets that contradict each other; `mcmle` steps, tests and inverts on the free coordinates only (also under `missing=:mle`); samplers run on `_sampler_theta(θ)` (±Inf → ±1e300, so 0·offset = 0 and no move against the constraint is accepted; chains with an infinite offset start from the observed network); the exact reference normaliser handles fixed dyads through `_dyad_logZ` (0 for a forbidden tie, θ_finite'δ for a forced one) and `_finite_dot` (the conditional log-likelihood, R's convention); an infinite offset on a dyad-DEPENDENT statistic (`Offset(Triangle(), -Inf)`) is honoured by the sampler but has no dyad-independent reference, so `mcmle` returns `loglik = NaN` with `_no_loglik_reason`. Results report R's convention: the fixed value, SE 0, zero vcov rows, `dof`/AIC/BIC over the estimated coefficients, BIC nobs = the dyads a −Inf offset leaves free. Pinned by the provenanced `offset_ergm.toml` (R's exact MPLE/MLE of two FMH offset models, an flomarriage MCMLE vs R's eleven-seed mean).

**The statistic protocol is shared, not ERGM's** (NetworkCore.jl `src/statistics.jl`): `compute`, `name` and `compute_all` are empty generics defined in the foundation and imported by name here (`import NetworkCore: compute, name, compute_all`), exactly like `gof`. ERGM adds the term methods; REM.jl adds relational-event methods with a different signature; they are methods of ONE function, so `ERGM.compute === REM.compute` and `using ERGM, REM` leaves the verbs usable unqualified. Never define a local `compute`/`name`; the variants correctly do `import ERGM: name, compute`, which resolves to the shared generics.

**Term traits are a public protocol** (`src/terms/traits.jl`): `required_vertex_attributes(term)` / `required_edge_attributes(term)` (tuples of Symbols, default `()`), `requires_directed(term)` / `requires_undirected(term)` (default `false`), `is_dyad_dependent(term)` (conservative default `true`), and `NetworkCore.supports_missing(term)` (default `false` — every built-in term counts a masked dyad at face value; the principled missing-data treatments live in the *estimators*, see below). All are exported and documented with runnable examples. Formula validation and materialization read the *traits*, never a term's fields, so a term from any package participates in exactly the same checks as a built-in (`ERGMUserterms.validate_term` exercises each declaration). The 0.1-era private aliases (`_requires_directed`, `_requires_undirected`, `_vertex_attribute`) are gone; the traits are the API. **Undirected-only terms are exactly R's**: `Degree`, `Kstar` and `GWDegree` declare `requires_undirected`, and their own `compute`/`change_stat` call `_refuse_directed` (a type-level branch, free in the hot loops); the ONE refusal message is `_undirected_only_message(t)`, which names the directed counterpart via `_directed_variant_hint` (`OStar`/`IStar`, `GWODegree`/`GWIDegree`, `ODegree`/`IDegree`). `OStar`/`IStar` (statnet `ostar`/`istar`) are the directed k-star terms and declare `requires_directed`. **NA-completeness validation**: `validate_formula` (extension API, documented) also refuses a declared vertex attribute that is not set on every vertex (or set to `missing`/`nothing`) — `_vertices_without_value` + `_incomplete_attribute_error`, naming term, attribute, count and vertex ids, as statnet refuses NA — so the zero-code branches in `_attribute_codes`/`_matches`/`_mismatches`/`_mix_matches` are unreachable through `ERGMModel` (kept as defensive code), `_float_attribute_vector` snapshots without a `default=`, and the raw `NodeCov`/`AbsDiff` read through `_vertex_value`, which throws rather than zero-fills. Every geometrically weighted term takes `decay >= 0` (`_check_decay`; the α = 0 weights are exact because `0^0 == 1`), and `name` goes through `_decay_label` so an integer-valued decay prints as R prints it (`gwesp.fixed.0`, `gwesp.fixed.1`; `GWDegree` is `gwdeg.fixed.<d>`, R's label; `AbsDiff(pow=2)` is `absdiff2.<attr>`). **Labels are direction-aware where the network is known**: R names a *directed* network's `gwesp`/`gwdsp` `gwesp.OTP.fixed.<d>` (every type, the default included) and the undirected one `gwesp.fixed.<d>` (type ignored), so `name(term, net)` — a two-argument method of the shared generic, default `name(term)` — resolves the label, `materialize(ts, net)` builds the model's `TermSet(terms, names)` from it, and `summary_stats` keys on it; the bare `name(GWESP(0.5))` keeps the undirected label for `:OTP`. **Every directed `GWDSP` type sums over ORDERED dyads** (R's `ddsp`): OSP/ISP used to be summed over unordered dyads at exactly half of R, change statistic included; the samplike rows of `ergm_terms.toml` pin all of gwesp/gwdsp OTP/ITP/OSP/ISP. **Self-loops are refused** at `ERGMModel` and by `summary_stats` (`_refuse_self_loops`, only when a loop is present; a `loops=true` network with none is modelled as loop-free), and `EdgeCov` sizes are validated (`_check_covariate_size`, also in its `compute`/`change_stat`). `Degree`/`IDegree`/`ODegree` hold `degrees::Vector{Int}`: a one-degree term is a statistic, a multi-degree term (`Degree(0:2)`) is a specification that `materialize` (extension API, documented; also `summary_stats`, via `_expand_degrees`) expands into one term per degree, and whose `compute`/`change_stat` throw via `_single_degree`.

**Core data flow**: Terms are collected into a `TermSet` (a tuple of terms plus their names; `compute_all`/`change_stat_all`/`change_stat_all!` and the MPLE key go through the **`@generated` `_compute_tuple`/`_change_stat_tuple`**, one statically dispatched call per term for ANY term count — `Base.map` over a tuple is unrolled only below 32 elements and boxed every Float64 from there on, ~30 KB per MH step / per MPLE dyad at p ≥ 32; the 36-statistic `edges + NodeMix(8 levels)` pins in the allocation testsets and `benchmark/regression_tests.jl` keep it at 0 B) (`collect_terms` normalizes a single term, a vector of terms, or a vector mixing terms with vectors of terms — `[Edges(), Degree(0:2)]` — and names any non-term element with its position; `fit_ergm` also has swapped-argument methods that throw an `ArgumentError` instead of a `MethodError`), wrapped in an `ERGMFormula` (`constraints=` is REFUSED with an `ArgumentError` when non-empty — constrained sampling is not implemented and the field used to be stored and never read), then combined with a `Network` into an `ERGMModel{T,D}`. `D` is the network's directedness at the type level (`Graphs.is_directed(model)`; there is no `directed` field), so `model.network` is a concrete `Network{T,D}` and the hot loops reading it are statically typed; `ERGMResult{T,D}` carries the same parameters (plus, `chain_lengths::Vector{Int}` — the per-chain row counts of `mcmc_samples`, empty for MPLE — and `boot_replicates::Union{Nothing,Matrix{Float64}}`) and `sample_networks` returns a concretely typed `Vector{Network{T,D}}`. Model construction REFUSES a two-mode network (`is_two_mode(net)`, or a `BipartiteNetwork`) with an `ArgumentError` — bipartite terms and the two-mode proposal are not implemented, and a one-mode fit would count the impossible within-mode dyads as observations — and validates the formula (`src/terms/materialize.jl`) against the term traits above. Attribute-based nodal terms are then *materialized* into typed twins (`MaterializedNodeCov`, ...) that snapshot the attribute into dense vectors, so hot-loop change statistics avoid the untyped attribute Dicts. Multi-level `NodeFactor` (first sorted level dropped by default — statnet's `base=1`), `NodeMatch(attr; diff=true)` without `level=` (every sorted level, or `levels=`, as R's `nodematch(diff=TRUE)`; `_nodematch_levels`) and multi-cell `NodeMix` (first cell dropped — `levels2=-1`) expand into one materialized statistic per level/cell at model construction. Fitting produces an `ERGMResult` containing coefficients, standard errors, p-values, fit statistics, `se_type` (`:hessian`/`:bootstrap`/`:mcmc`), `missing_method` (`:none`/`:available_case`/`:mle`/`:condition_on_face`; see below), `vcov_fisher`, `mcmc_se` and `mcmc_convergence`. `is_dyad_dependent(term)` classifies terms and the exported `has_dyad_dependent(model)` is THE predicate behind both the `show` caveat and `is_exact` (the variants should add methods to it rather than define same-named privates; `_has_dyad_dependent` is a deprecated, documented `const` alias). `show(::ERGMResult)` prints `coeftable(result)` — a `NetworkCore.CoefficientTable` built from the same vectors, so the printed table IS the inspectable one — plus a statnet-style caveat for pseudo-likelihood fits of dyad-dependent models, the missing-dyad treatment whenever the network carried a mask, the non-convergence caveat under `Converged: false`, and R's "MCMC %" line for MCMLE fits. The full StatsAPI surface (`coef`, `stderror`, `vcov`, `confint` (normal-theory), `loglikelihood`, `nobs`, `dof`, `aic`, `bic`, `coeftable`, `coefnames` — the StatsAPI binding NetworkCore exports, a copy of the term names) is defined on `ERGMResult`; the "StatsAPI surface is complete" testset pins it with `NetworkCore.check_statsapi(fit; required=(STATSAPI_VERBS..., :coefnames), strict=true)`.

**Missing dyads** (`src/missing.jl`): ERGM.jl honours the NetworkCore.jl missing-data contract (`supports_missing` / `require_observed` / `missing_policies`, imported by name because ERGM adds methods to the traits) with THREE treatments and no silent face-value read. `summary_stats(net, terms; missing=:error)` — statnet's `summary()` — is a descriptive statistic and calls `require_observed` with the generic `:face` as its only opt-in (`missing_policies(summary_stats) == (:error, :face)`); R's `summary()` treats an NA dyad as absent, which the masked fixture reproduces on an absent-copy under `missing=:face`. `compute`/`compute_all` stay protocol-level raw evaluations.

- **MPLE** drops masked dyads from the pseudo-likelihood (available-case; they still condition the change statistics of the observed dyads). `supports_missing(mple) == true`, no keyword, `missing_policies(mple) == (:error,)`, `missing_method = :available_case`. R's dyad-independent fit with NA dyads is exactly this logistic regression on the observed dyads — pinned to 1e-6 by the masked fixture (below).
- **`mcmle(...; missing=:mle)` is missing-data maximum likelihood** (Handcock & Gile 2010; what R `ergm()` does with NA ties). The likelihood is `Z_obs(θ)/Z(θ)`. Each iteration runs the *free* chain (`toggleable=:all`, every dyad) giving `ḡ`, `Σ_free`, and the *constrained* chain (`toggleable=:masked`, only the masked dyads, observed dyads fixed, `obs_burnin`/`obs_interval` = the dyad-scaled rule over the masked dyads) giving `ĝ_obs = Ê[g | Y_obs]`, `Σ_obs`. `ĝ_obs` replaces the observed statistics as the Newton target (`θ += γ Σ_free⁻¹ (ĝ_obs − ḡ)`); `mcmc_convergence(samples, target; target_samples=, target_chain_lengths=)` uses the per-draw sd `sqrt(var_free + var_obs)` for the t-ratios and `Σ_free/n_eff + Σ_obs/n_eff_obs` in the Hotelling test; `mcmle_covariance` inverts `Σ_free − Σ_obs` (Eq. 9) after a Cholesky PD check (NaN SEs + warning otherwise) and adds `V(Σ_mc,free + Σ_mc,obs)V`; the log-likelihood is `_bridge_logZ(:masked) − _bridge_logZ(:all)`, each from the exact `_dyad_independent_logZ(model, θ0; toggleable)` of its own dyad set. `missing_method = :mle`, `supports_missing(mcmle) == true`, `missing_policies(mcmle) == (:error, :condition_on_face, :mle)`, `nobs` = observed dyads, `show` says "missing-data maximum likelihood (masked dyads integrated out by a constrained chain)", `approximations` lists the MC error of the target. Under dyad independence the fit coincides with the available-case MPLE (the convergence test passes at the MPLE and no step is taken) and both bridges are exact.
- **`missing=:condition_on_face`** freezes each masked dyad at its stored face value (`toggleable=:free` never proposes it) and scores it as recorded — the model *conditional* on the face values, a different estimand, warned by `_warn_condition_on_face` (user-facing entry points only, so one warning per call). On the masked fixture it differs from `:mle` by 0.11 on both coefficients (twenty R seed sds); pinned.

The default `missing=:error` refuses via `require_observed(...; face_ok=false)` — the shared text never advertises `missing=:face`, which ERGM rejects — plus bullets naming the opt-ins the routine takes (`_MLE_HINT` first, then `_CONDITION_ON_FACE_HINT`, for `mcmle`; only the latter for the samplers). `_guard_missing(net, policy; context, policies)` validates and returns the method in force. **The samplers (`mh_sample`, `sample_networks`, `simulate_ergm`, `gof`) accept only `(:error, :condition_on_face)`** and refuse `:mle` with `_mle_not_defined_message` (a simulated network has a value at every dyad, so simulation under missing data is not defined); `gof` is the shared generic, so ERGM declares the per-result-type form `missing_policies(gof, ::Type{<:ERGMResult})`. The "samplers reject masked networks" testset asserts every refusal contains `:condition_on_face`, never `missing=:face`, and that only `mcmle`'s names `missing=:mle`.

**Estimation** (`src/estimation/`):
- `mple.jl` - **Boundary statistics** (`_boundary_columns_once(X, n_tot, n_one)`, R's attainable-range test): a column is at its minimum iff every dyad with a positive change is a non-tie AND every dyad with a negative change is a tie (mirror for the maximum) — the sign pattern is irrelevant (a mixed-sign `nodecov` column used to be skipped and Newton "converged" on the asymptote at −42 with SE 28,000). `boundary_columns` repeats the test on the reduced design after each drop (the exact pseudo-likelihood limit; on the mixed-sign fixture design nodecov → −Inf then edges → +Inf). **R's attainable range** (`attainable_range(term, net)` in `extended.jl`, R's `minval`/`maxval` read off `ergm_model()` for ergm 4.12: counts from 0, degree-type counts to n, `edges`/`mutual` to the dyad count, `(-Inf, Inf)` for `nodecov`/`absdiff`/`edgecov`/third-party terms; GWESP/GWDSP/GWNSP get `(0, Inf)` deliberately — R declares no bound and fits a finite, unidentified coefficient at 0) and `extreme_statistics(ts, net)` (R's `ergm.checkextreme.model`: observed statistic == an end → `(col, :min|:max)`, offsets skipped) catch what the design cannot: a column whose change statistics are ALL ZERO (a singleton level's `nodemix` cell, `triangle` with no two-path, `degree1` with every degree ≥ 3) — Newton used to stall at θ = 0 for every coefficient. They seed `boundary_columns(...; fixed=extreme)`. `_mple_fit` (= `_mple_data` + `extreme_statistics` + `mple_fit_design(X, n_tot, n_one, names; warn, extreme)`) warns R's sentence ("observed statistic(s) … are at their smallest attainable values. Their coefficients will be fixed at -Inf", `warn_boundary`), fixes the coefficient at ∓Inf (SE 0, z ∓Inf, p 0), then **aliasing** (`_aliased_columns(X, rows, cols)`: Gram–Schmidt in column order, R's glm rule — a zero column or one in the span of earlier ones) reports a non-identifiable coefficient as NaN (SE NaN, R's NA) with R's "not varying"/"linear dependence" warning (`_warn_aliased`), and fits the rest on the rows the dropped columns do not touch (one code path in `mple_fit_design`; `_mple_fit_dropped` is gone) — R's `drop=TRUE` numbers (edges = logit(12/300) on the docs' separated network), returning `n_kept` (those rows' dyads) so that **`dof` counts the finite coefficients and BIC uses `n_kept`** — R's `logLik` df/nobs (df 1, BIC = −2ℓ + log 300; `nobs(fit)` stays 435), pinned by the provenanced `sep_*` rows. `show` and `approximations` derive the note from the coefficients (`_fixed_coefficient_note`). **Separation by a combination of columns** is the shared NetworkCore verdict `logistic_separation(X, n_tot, n_one)` (an exact LP with a rationally certified direction, as R's `mple.existence`), run in `mple_fit_design` on the design actually fitted (after the boundary drop, offset-fixed rows removed) and following the ecosystem's separation policy: `NetworkCore.warn_separation(context, v, names; estimate, note)` with R's "The MPLE does not exist!" as the default `note.separation`, the verdict returned as `verdict`, `converged = false`, `separated = true` and `separated_terms` (names of `v.terms`) in the fit tuple and on `ERGMResult.separated_terms`, and `mple` sets every z/p to NaN (`confint` returns NaN; `se=:bootstrap` is refused); `is_exact` requires `converged` and all-finite coefficients. `_separated` and `_warn_separated` are deleted (no caller; a variant reads the `verdict` `mple_fit_design` returns, or calls NetworkCore's verdict directly). **`mcmle` applies R's drop itself**: it builds the design ONCE (`_mple_data`), computes `_model_boundary(model, X, n_tot, n_one, extreme)` (extreme ∪ the iterated design test on the dyads the true offsets leave free) BEFORE any start, warns R's sentence (`_warn_drop`), and treats the dropped columns as fixed ∓Inf coordinates (`fixed_mask`/`fixed_vals` beside the offsets: excluded from `free`, `_sampler_theta` turns them into ±1e300 so the sampler holds the statistic at its bound, a dyad-dependent one makes `constrained_dd` → loglik NaN with `_no_loglik_reason`); the MPLE start is `_mple_fit_offsets(...; extreme=boundary)` (true offsets as offsets, drops as the MPLE's row removal). Dyad-independent aliased columns are held at 0 (any value is the same model) and reported NaN (`θ_report`; `_simulation_theta` simulates them at 0); a dyad-dependent aliased column is refused unless `init=`. `drop=false` (on `mple`, `mcmle`, `fit_ergm`) is the strict mode: `_refuse_no_drop` throws BEFORE any start (no warning precedes it — pinned); the curved MCMLE always refuses a boundary (offsets and curved terms are not combined). Every coefficient fixed → "nothing to estimate", naming them. A separated start is refused pointing at `init=`. `_mple_data` builds a compressed dyad-level design (unique change-statistic rows with `n_tot`/`n_one` multiplicities; keyed on an `NTuple{p,Float64}` built on the stack, so the per-dyad sweep allocates nothing and the build allocates O(unique rows) — pinned by "MPLE design build allocates O(unique rows)"). `_mple_fit` is **Newton–Raphson on the shared kernel**: `f = logistic_derivatives(X, n_tot, n_one)` maximized by `newton_fit(f, zeros(p); maxiter=100, tol=1e-8)`; `newton_fit` returns NaN SEs with a warning when the negative Hessian is not PD, and `mple` warns on `converged == false` (also listed by `approximations`). The provenanced flomarriage fixture agrees with R to 8.9e-13 on the coefficients and 4.8e-8 on the SEs (asserted at 1e-6). `se=:bootstrap` (validated by `NetworkCore.check_se`) adds parametric-bootstrap SEs through `NetworkCore.bootstrap_cov` (ERGM supplies only the simulate/refit callbacks; the simulations condition masked dyads on their face value, and say so). **Replicates without a finite MPLE are excluded**: `refit` runs `_mple_fit(...; warn=false)` and returns a NaN row when the replicate's fit is a drop (∓Inf) or separated (`converged == false`); `_mple_bootstrap_cov` recomputes the covariance on the finite rows (≥ 2 required, ArgumentError otherwise), warns ONCE ("k of n_boot bootstrap refits had no finite MPLE … about the simulated replicates"), and returns the full replicate matrix, stored as `fit.boot_replicates` — `_boot_exclusion_note` derives the `show`/`approximations` sentence from it. `se=:bootstrap` is refused when the point estimate has a ∓Inf coefficient. Pinned on `[Edges(), Triangle()]` (which used to return NaN SEs). `fit_ergm(net, terms; method=:auto|:mple|:mcmle, kwargs...)` carries the definition; `const ergm = fit_ergm`. **The default `method=:auto` is R's rule**, the `public` `resolve_method(method, model_or_Bool; exact=:mple, mcmc=:mcmle, methods, context)`: `exact` when `has_dyad_dependent(model)` is false (the MPLE is then the exact MLE), `mcmc` otherwise; the variants reuse it with their own estimator names (TERGM: `exact=:cmple, mcmc=:cmle`). `_check_estimator_keywords` refuses, with an `ArgumentError` naming the estimator that takes it, a keyword the chosen estimator does not accept (read from `Base.kwarg_decl` of `mple`/`mcmle`) — typically `se=:bootstrap` on a dyad-dependent formula that `:auto` sends to the MCMLE. Tests and docs that want the MPLE of a dyad-dependent formula pass `method=:mple` explicitly.

## Not implemented (disclosed, not silently mis-fit)

The absent term families (sender/receiver attribute terms `nodeicov`/`nodeocov`/`nodeifactor`/`nodeofactor`; `ttriple`/`ctriple`/`transitiveties`/`cyclicalties`/`asymmetric`; the `dsp`/`nsp` count terms and `esp`'s `RTP` type; `isolates`, `balance`, `cycle`, `smalldiff`, `nodematch(keep=)` — no counterpart, so nothing to call), curved terms other than `gwesp`/`gwdegree` (and a curved term with an offset or `missing=:mle`), bipartite terms and two-mode networks (refused at `ERGMModel`), `constraints=` (refused at `ERGMFormula` and `fit_ergm`), an observed network violating an infinite offset (refused; R fits it), the log-likelihood of an MCMLE with an infinite dyad-dependent offset (NaN), SPDyad as the default of the samplers other than `mcmle` (`simulate_ergm`/`gof`/`mh_sample`/`sample_networks`/MPLE bootstrap default to `:tnt`; R's `simulate` uses SPDyad), attribute terms with NA values (refused at `ERGMModel`), self-loops (refused at `ERGMModel` when present), R's `drop=FALSE` on a boundary statistic (both estimators do `drop=TRUE`; `drop=false` refuses), a boundary statistic in a curved model (refused), a dyad-dependent statistic that does not vary at the observed network under `mcmle` (refused unless `init=`; R starts it at 0), and simulation/GOF *under* missing data (a simulated network has a value at every dyad: `simulate_ergm`/`gof` on a masked network offer only the warned `:condition_on_face` and refuse `:mle` with an explanation). The list lives in the README "Not implemented" section, the terms guide admonition and the CHANGELOG "Known limitations" heading; keep the three in sync.

## Key Dependencies

- **NetworkCore.jl** - the ecosystem foundation: the `Network{T,D}` data structure with vertex/edge attributes and the missing-dyad mask (`set_missing_dyad!`, `missing_dyads`, `n_missing_dyads`), the missing-data, conversion and tied-event contracts, and the shared numerics ERGM imports by name (`newton_fit`, `logistic_derivatives`, `z_pvalues`, `check_se`, `bootstrap_cov`, `print_coeftable`/`CoefficientTable`, `mc_pvalue`, `load_golden`); resolved via `[sources]` from `../NetworkCore.jl` (not in General)
- **Graphs.jl** - graph algorithms; `Network` wraps a `Graphs` graph internally (accessed via `net.graph` for things like `gdistances`)
- **Distributions.jl** - `Normal`/`Chisq`/`FDist` quantiles and tails for `confint`, the Hummel step control and the Hotelling convergence test (p-values themselves go through `NetworkCore.z_pvalues`)
- **StatsAPI.jl** - the generics of the StatsAPI surface (`coef` … `coeftable`), each given a method on `ERGMResult`
- **PrecompileTools.jl** - the `@compile_workload` at the end of `src/ERGM.jl`
- **Printf** (stdlib) - `@sprintf("%.3g")` in `_fmt3`, the three-significant-digit formatter of every MCMLE/bridge diagnostic (a rounded Float64's `string` printed `6.969999999999999e-32`)

No optimizer package is a dependency: the MPLE runs on NetworkCore's Newton kernel. StatsBase and SparseArrays are NOT dependencies either (nothing in `src` used them; StatsBase stays a test extra for the `using ERGM, StatsBase` co-loading check).

## Conventions

- All term statistics return `Float64`.
- `change_stat` returns the state-independent add-direction change statistic `g(y⁺ij) − g(y⁻ij)`. It must NOT depend on whether the edge currently exists; the MH sampler negates it for removal proposals.
- Term `name()` functions use R ergm-style lowercase names (e.g., `"edges"`, `"nodematch.gender"`, `"gwesp.fixed.0.5"`, `"gwdeg.fixed.1"`); fixed decays print through `_decay_label` exactly as R prints them.
- Internal/private functions are prefixed with underscore; mutators end in `!`; statnet-mirroring functions are snake_case.
- All randomness flows through `rng::AbstractRNG` keywords (default `Random.default_rng()`); never call bare `rand()` in sampling/fitting code. Parallel loops draw one seed per task from the caller's rng.
- Every behavioural change gets a `CHANGELOG.md` `[0.2.0] - Unreleased` entry in the right section.
- Every export (and `public` name) has a docstring with a runnable, self-contained ```julia example; the suite executes them.

## Project Overview

ERGM.jl is a Julia port of the R `ergm` package (from StatNet) for fitting, simulating, and diagnosing Exponential-Family Random Graph Models. It provides MPLE and MCMLE estimation (including missing-data maximum likelihood), MCMC network simulation, and goodness-of-fit diagnostics. It is the core of the ERGM bundle: ERGMCount, ERGMEgo, ERGMMulti, ERGMRank, ERGMUserterms and TERGM depend on it and build on the internals named below.

## Architecture

**Type hierarchy** (`src/terms/base.jl`): `AbstractERGMTerm` is the root, with subtypes `StructuralTerm`, `NodalTerm`, `DyadicTerm`, and `ConstraintTerm` (reserved; constraints are refused, see below). Each term must implement `compute(term, net) -> Float64` and `change_stat(term, net, i, j) -> Float64`.

**The statistic protocol is shared, not ERGM's** (Networks.jl `src/statistics.jl`): `compute`, `name` and `compute_all` are empty generics defined in the foundation and imported by name here (`import Networks: compute, name, compute_all`), exactly like `gof`. ERGM adds the term methods; REM.jl adds relational-event methods with a different signature; they are methods of ONE function, so `ERGM.compute === REM.compute` and `using ERGM, REM` leaves the verbs usable unqualified. Never define a local `compute`/`name`; the variants correctly do `import ERGM: name, compute`, which resolves to the shared generics.

**Term traits are a public protocol** (`src/terms/traits.jl`): `required_vertex_attributes(term)` / `required_edge_attributes(term)` (tuples of Symbols, default `()`), `requires_directed(term)` / `requires_undirected(term)` (default `false`), `is_dyad_dependent(term)` (conservative default `true`), and `Networks.supports_missing(term)` (default `false` — every built-in term counts a masked dyad at face value; the principled missing-data treatments live in the *estimators*, see below). All are exported and documented with runnable examples. Formula validation and materialization read the *traits*, never a term's fields, so a term from any package participates in exactly the same checks as a built-in (`ERGMUserterms.validate_term` exercises each declaration). The private names survive as **`const` aliases of the same generics** (`_requires_directed`, `_requires_undirected`; `_vertex_attribute` returns the first required vertex attribute or `nothing`), declared `public` and documented, because TERGM.jl ships `ERGM._requires_directed(::Delrecip) = true`. **Undirected-only terms are exactly R's** (panel 2026-09, item 12): `Degree`, `Kstar` and `GWDegree` declare `requires_undirected`, and their own `compute`/`change_stat` call `_refuse_directed` (a type-level branch, free in the hot loops); the ONE refusal message is `_undirected_only_message(t)`, which names the directed counterpart via `_directed_variant_hint` (`OStar`/`IStar`, `GWODegree`/`GWIDegree`, `ODegree`/`IDegree`). `OStar`/`IStar` (statnet `ostar`/`istar`) are the directed k-star terms and declare `requires_directed`. **NA-completeness validation**: `_validate_formula` (`public`, documented) also refuses a declared vertex attribute that is not set on every vertex (or set to `missing`/`nothing`) — `_vertices_without_value` + `_incomplete_attribute_error`, naming term, attribute, count and vertex ids, as statnet refuses NA — so the zero-code branches in `_attribute_codes`/`_matches`/`_mismatches`/`_mix_matches` are unreachable through `ERGMModel` (kept as defensive code), `_float_attribute_vector` snapshots without a `default=`, and the raw `NodeCov`/`AbsDiff` read through `_vertex_value`, which throws rather than zero-fills. Every geometrically weighted term takes `decay >= 0` (`_check_decay`; the α = 0 weights are exact because `0^0 == 1`), and `name` goes through `_decay_label` so an integer-valued decay prints as R prints it (`gwesp.fixed.0`, `gwesp.fixed.1`; `GWDegree` is `gwdeg.fixed.<d>`, R's label; `AbsDiff(pow=2)` is `absdiff2.<attr>`). **Labels are direction-aware where the network is known** (round 2): R names a *directed* network's `gwesp`/`gwdsp` `gwesp.OTP.fixed.<d>` (every type, the default included) and the undirected one `gwesp.fixed.<d>` (type ignored), so `name(term, net)` — a two-argument method of the shared generic, default `name(term)` — resolves the label, `_materialize(ts, net)` builds the model's `TermSet(terms, names)` from it, and `summary_stats` keys on it; the bare `name(GWESP(0.5))` keeps the undirected label for `:OTP`. **Every directed `GWDSP` type sums over ORDERED dyads** (R's `ddsp`): OSP/ISP used to be summed over unordered dyads at exactly half of R, change statistic included; the samplike rows of `ergm_terms.toml` pin all of gwesp/gwdsp OTP/ITP/OSP/ISP. **Self-loops are refused** at `ERGMModel` (`_refuse_self_loops`, only when a loop is present; a `loops=true` network with none is modelled as loop-free), and `EdgeCov` sizes are validated (`_check_covariate_size`, also in its `compute`/`change_stat`). `Degree`/`IDegree`/`ODegree` hold `degrees::Vector{Int}`: a one-degree term is a statistic, a multi-degree term (`Degree(0:2)`) is a specification that `_materialize` (`public`, documented; also `summary_stats`, via `_expand_degrees`) expands into one term per degree, and whose `compute`/`change_stat` throw via `_single_degree`.

**Core data flow**: Terms are collected into a `TermSet` (a tuple of terms plus their names; `compute_all`/`change_stat_all`/`change_stat_all!` and the MPLE key go through the **`@generated` `_compute_tuple`/`_change_stat_tuple`**, one statically dispatched call per term for ANY term count — `Base.map` over a tuple is unrolled only below 32 elements and boxed every Float64 from there on, ~30 KB per MH step / per MPLE dyad at p ≥ 32; the 36-statistic `edges + NodeMix(8 levels)` pins in the allocation testsets and `benchmark/regression_tests.jl` keep it at 0 B) (`_collect_terms` normalizes a single term, a vector of terms, or a vector mixing terms with vectors of terms — `[Edges(), Degree(0:2)]` — and names any non-term element with its position; `fit_ergm` also has swapped-argument methods that throw an `ArgumentError` instead of a `MethodError`), wrapped in an `ERGMFormula` (`constraints=` is REFUSED with an `ArgumentError` when non-empty — constrained sampling is not implemented and the field used to be stored and never read), then combined with a `Network` into an `ERGMModel{T,D}`. `D` is the network's directedness at the type level (`Graphs.is_directed(model)`; there is no `directed` field), so `model.network` is a concrete `Network{T,D}` and the hot loops reading it are statically typed; `ERGMResult{T,D}` carries the same parameters (plus, since round 3, `chain_lengths::Vector{Int}` — the per-chain row counts of `mcmc_samples`, empty for MPLE — and `boot_replicates::Union{Nothing,Matrix{Float64}}`) and `sample_networks` returns a concretely typed `Vector{Network{T,D}}`. Model construction REFUSES a two-mode network (`is_two_mode(net)`, or a `BipartiteNetwork`) with an `ArgumentError` — bipartite terms and the two-mode proposal are not implemented, and a one-mode fit would count the impossible within-mode dyads as observations — and validates the formula (`src/terms/materialize.jl`) against the term traits above. Attribute-based nodal terms are then *materialized* into typed twins (`MaterializedNodeCov`, ...) that snapshot the attribute into dense vectors, so hot-loop change statistics avoid the untyped attribute Dicts. Multi-level `NodeFactor` (first sorted level dropped by default — statnet's `base=1`) and multi-cell `NodeMix` (first cell dropped — `levels2=-1`) expand into one materialized statistic per level/cell at model construction. Fitting produces an `ERGMResult` containing coefficients, standard errors, p-values, fit statistics, `se_type` (`:hessian`/`:bootstrap`/`:mcmc`), `missing_method` (`:none`/`:available_case`/`:mle`/`:condition_on_face`; see below), `vcov_fisher`, `mcmc_se` and `mcmc_convergence`. `is_dyad_dependent(term)` classifies terms and the exported `has_dyad_dependent(model)` is THE predicate behind both the `show` caveat and `is_exact` (the variants should add methods to it rather than define same-named privates; `_has_dyad_dependent` is a deprecated, documented `const` alias). `show(::ERGMResult)` prints `coeftable(result)` — a `Networks.CoefficientTable` built from the same vectors, so the printed table IS the inspectable one — plus a statnet-style caveat for pseudo-likelihood fits of dyad-dependent models, the missing-dyad treatment whenever the network carried a mask, the non-convergence caveat under `Converged: false`, and R's "MCMC %" line for MCMLE fits. The full StatsAPI surface (`coef`, `stderror`, `vcov`, `confint` (normal-theory), `loglikelihood`, `nobs`, `dof`, `aic`, `bic`, `coeftable`) is defined on `ERGMResult`; the "StatsAPI surface is complete" testset pins it with `Networks.check_statsapi(fit; strict=true)`.

**Missing dyads** (`src/missing.jl`; panel 2026-09, items 5 and 32): ERGM.jl honours the Networks.jl missing-data contract (`supports_missing` / `require_observed` / `missing_policies`, imported by name because ERGM adds methods to the traits) with THREE treatments and no silent face-value read. `summary_stats(net, terms; missing=:error)` — statnet's `summary()` — is a descriptive statistic and calls `require_observed` with the generic `:face` as its only opt-in (`missing_policies(summary_stats) == (:error, :face)`); R's `summary()` treats an NA dyad as absent, which the masked fixture reproduces on an absent-copy under `missing=:face`. `compute`/`compute_all` stay protocol-level raw evaluations.

- **MPLE** drops masked dyads from the pseudo-likelihood (available-case; they still condition the change statistics of the observed dyads). `supports_missing(mple) == true`, no keyword, `missing_policies(mple) == (:error,)`, `missing_method = :available_case`. R's dyad-independent fit with NA dyads is exactly this logistic regression on the observed dyads — pinned to 1e-6 by the masked fixture (below).
- **`mcmle(...; missing=:mle)` is missing-data maximum likelihood** (Handcock & Gile 2010; what R `ergm()` does with NA ties). The likelihood is `Z_obs(θ)/Z(θ)`. Each iteration runs the *free* chain (`toggleable=:all`, every dyad) giving `ḡ`, `Σ_free`, and the *constrained* chain (`toggleable=:masked`, only the masked dyads, observed dyads fixed, `obs_burnin`/`obs_interval` = the dyad-scaled rule over the masked dyads) giving `ĝ_obs = Ê[g | Y_obs]`, `Σ_obs`. `ĝ_obs` replaces the observed statistics as the Newton target (`θ += γ Σ_free⁻¹ (ĝ_obs − ḡ)`); `mcmc_convergence(samples, target; target_samples=, target_chain_lengths=)` uses the per-draw sd `sqrt(var_free + var_obs)` for the t-ratios and `Σ_free/n_eff + Σ_obs/n_eff_obs` in the Hotelling test; `_mcmle_covariance` inverts `Σ_free − Σ_obs` (Eq. 9) after a Cholesky PD check (NaN SEs + warning otherwise) and adds `V(Σ_mc,free + Σ_mc,obs)V`; the log-likelihood is `_bridge_logZ(:masked) − _bridge_logZ(:all)`, each from the exact `_dyad_independent_logZ(model, θ0; toggleable)` of its own dyad set. `missing_method = :mle`, `supports_missing(mcmle) == true`, `missing_policies(mcmle) == (:error, :condition_on_face, :mle)`, `nobs` = observed dyads, `show` says "missing-data maximum likelihood (masked dyads integrated out by a constrained chain)", `approximations` lists the MC error of the target. Under dyad independence the fit coincides with the available-case MPLE (the convergence test passes at the MPLE and no step is taken — the N7 behaviour, here a feature) and both bridges are exact.
- **`missing=:condition_on_face`** freezes each masked dyad at its stored face value (`toggleable=:free` never proposes it) and scores it as recorded — the model *conditional* on the face values, a different estimand, warned by `_warn_condition_on_face` (user-facing entry points only, so one warning per call). On the masked fixture it differs from `:mle` by 0.11 on both coefficients (twenty R seed sds); pinned.

The default `missing=:error` refuses via `require_observed(...; face_ok=false)` — the shared text never advertises `missing=:face`, which ERGM rejects — plus bullets naming the opt-ins the routine takes (`_MLE_HINT` first, then `_CONDITION_ON_FACE_HINT`, for `mcmle`; only the latter for the samplers). `_guard_missing(net, policy; context, policies)` validates and returns the method in force. **The samplers (`mh_sample`, `sample_networks`, `simulate_ergm`, `gof`) accept only `(:error, :condition_on_face)`** and refuse `:mle` with `_mle_not_defined_message` (a simulated network has a value at every dyad, so simulation under missing data is not defined); `gof` is the shared generic, so ERGM declares the per-result-type form `missing_policies(gof, ::Type{<:ERGMResult})`. The "samplers reject masked networks" testset asserts every refusal contains `:condition_on_face`, never `missing=:face`, and that only `mcmle`'s names `missing=:mle`.

**Estimation** (`src/estimation/`):
- `mple.jl` - **Boundary statistics** (`_boundary_columns(X, n_tot, n_one)`, R's attainable-range test): a column is at its minimum iff every dyad with a positive change is a non-tie AND every dyad with a negative change is a tie (mirror for the maximum) — the sign pattern is irrelevant (round 3: a mixed-sign `nodecov` column used to be skipped and Newton "converged" on the asymptote at −42 with SE 28,000). `_boundary_columns_iterated` repeats the test on the reduced design after each drop (the exact pseudo-likelihood limit; on the mixed-sign fixture design nodecov → −Inf then edges → +Inf). `_mple_fit` (= `_mple_data` + `_mple_fit_design(X, n_tot, n_one, names; warn)`) warns R's sentence ("observed statistic(s) … are at their smallest attainable values. Their coefficients will be fixed at -Inf", `_warn_boundary`) and `_mple_fit_dropped` fixes the coefficient at ∓Inf (SE 0, z ∓Inf, p 0) and fits the rest on the rows the dropped columns do not touch — R's `drop=TRUE` numbers (edges = logit(12/300) on the docs' separated network), returning `n_kept` (those rows' dyads) so that **`dof` counts the finite coefficients and BIC uses `n_kept`** — R's `logLik` df/nobs (df 1, BIC = −2ℓ + log 300; `nobs(fit)` stays 435), pinned by the provenanced `sep_*` rows. `show` and `approximations` derive the note from the coefficients (`_fixed_coefficient_note`). **Separation by a combination of columns** (`_separated(f, X, n_tot, n_one, θ, se)`): R's `mple.existence` is an exact LP; ERGM.jl has none and requires BOTH asymptote signatures — a perfectly predicted row at |η| > 18.42 (fitted probability within 1e-8 of 0/1) AND a next Newton step `−H⁻¹g` > 1e-3·‖θ‖ (or a singular Hessian) — then `_warn_separated` ("the MPLE does not exist (perfect separation)", R's sentence quoted) and `converged = false` (`separated = true` in the internal fit tuple); `is_exact` requires `converged` and all-finite coefficients. `mcmle` builds the design ONCE (`_mple_data`), runs `_refuse_boundary_statistics(model, X, n_tot, n_one)` BEFORE computing any start (no `mple:` warning precedes the ArgumentError — pinned), takes its start from `_mple_fit_design(...; warn=false)`, and refuses a separated start pointing at `init=`. `_mple_data` builds a compressed dyad-level design (unique change-statistic rows with `n_tot`/`n_one` multiplicities; keyed on an `NTuple{p,Float64}` built on the stack, so the per-dyad sweep allocates nothing and the build allocates O(unique rows) — pinned by "MPLE design build allocates O(unique rows)"). `_mple_fit` is **Newton–Raphson on the shared kernel**: `f = logistic_derivatives(X, n_tot, n_one)` maximized by `newton_fit(f, zeros(p); maxiter=100, tol=1e-8)`; `newton_fit` returns NaN SEs with a warning when the negative Hessian is not PD, and `mple` warns on `converged == false` (also listed by `approximations`). The provenanced flomarriage fixture agrees with R to 8.9e-13 on the coefficients and 4.8e-8 on the SEs (asserted at 1e-6). `se=:bootstrap` (validated by `Networks.check_se`) adds parametric-bootstrap SEs through `Networks.bootstrap_cov` (ERGM supplies only the simulate/refit callbacks; the simulations condition masked dyads on their face value, and say so). **Replicates without a finite MPLE are excluded** (round 3): `refit` runs `_mple_fit(...; warn=false)` and returns a NaN row when the replicate's fit is a drop (∓Inf) or separated (`converged == false`); `_mple_bootstrap_cov` recomputes the covariance on the finite rows (≥ 2 required, ArgumentError otherwise), warns ONCE ("k of n_boot bootstrap refits had no finite MPLE … about the simulated replicates"), and returns the full replicate matrix, stored as `fit.boot_replicates` — `_boot_exclusion_note` derives the `show`/`approximations` sentence from it. `se=:bootstrap` is refused when the point estimate has a ∓Inf coefficient. Pinned on `[Edges(), Triangle()]` (which used to return NaN SEs). `_z_pvalues` is a deprecated, documented `const` alias of `Networks.z_pvalues` (the ONE z → p helper) kept only until TERGM/ERGMMulti stop reaching into it. `fit_ergm(net, terms; method=:mple|:mcmle, kwargs...)` carries the definition; `const ergm = fit_ergm`.
- `mcmle.jl` - Initializes from MPLE (or `init=`), then iterates Hummel-stepped Newton-Raphson updates using MCMC-sampled statistics; convergence via per-statistic t-ratios plus a Hotelling T² test — the `public` `mcmc_convergence(samples, targets; conv_threshold, hotelling_alpha, chain_lengths, target_samples, target_chain_lengths) -> (converged, t_ratios, hotelling_p, n_eff)`, called at every full-step iteration and once more on the final sample (recorded as `fit.mcmc_convergence::MCMLEConvergence`; ERGMEgo should call it instead of its 1 % relative rule). The iteration cap is `maxiter` (`max_iter` is a deprecated shim that warns once and is honoured, `tol` a deprecated no-op). **Non-convergence is loud**: `@warn` after the loop quoting the last max t-ratio / Hotelling p / step length and pointing at `init=coef(fit)`, the same sentence (`_nonconvergence_caveat`) under `Converged: false` in `show` and in `approximations(fit)`. **`n_chains`**: `_mcmc_sample(model, θ, n, burnin, interval; rng, missing, n_chains, toggleable) -> (samples, chain_lengths)` runs one `mh_sample` on the caller's rng for `n_chains == 1` (bit-identical to the single-chain sampler, which the provenanced fixture relies on) and otherwise splits `n_samples` exactly as `sample_networks` does (per-chain counts, `seeds = rand(rng, UInt64, n_chains)`, `Threads.@spawn`, every chain from the observed network, concatenated in chain order — bit-identical at any thread count, pinned by a fresh-process test at a different `--threads`); `_effective_sample_size(samples, chain_lengths)` SUMS the per-chain Geyer ESSs. **Standard errors include the Monte-Carlo term** (Hunter & Handcock 2006 §3.3): `vcov = V + V·Σ_mc·V` with `V = inv(cov(final_samples))` (`vcov_fisher`) and `Σ_mc = _mc_cov_of_mean(samples, chain_lengths)`; `mcmc_se(fit)` is exported and `show` prints R's "MCMC %" column — `_mcmc_percent` is R's own definition `round(100·(se − se_fisher)/se)` (`ergm:::summary.ergm`: `100*(tot.se − mod.se)/tot.se`, the share of the STANDARD ERROR, not of its variance), printed as `MCMC % of the standard error (100·(se − se_fisher)/se)`. `_mcmle_covariance` is the one place that computes them (and the missing-data variant). **`bridge_rungs=0`** skips the bridge (`loglik = aic = bic = NaN`, `show` prints "not estimated", `approximations` lists it); the bridge runs last, so coefficients/SEs are bit-identical with and without it. `_bridge_loglik(model, θ, obs_stats) = θ'obs_stats − _bridge_logZ(model, θ; toggleable=:free)`; `_bridge_logZ` is a path-sampling ladder from the exact dyad-independent reference (`_dyad_independent_logZ`, over the same `toggleable` dyad set) to θ̂, trapezoid-integrated, rungs parallelized with deterministic per-rung seeds.
- There is no `newton.jl`. **`newton_fit` and `logistic_derivatives` are Networks.jl's** (`public` there), imported by name and re-exported so `ERGM.newton_fit === Networks.newton_fit`. The variants and REM/Relevent all run on that one pair. **Never paste a Newton loop or a logistic loop back into a package.**

**Simulation** (`src/mcmc/simulation.jl`): everything is built on the exported Metropolis kernel **`mh_toggle!(rng, θ, delta, propose, change!, apply!, on_sample; burnin, interval, n_samples)`** (panel 2026-09, item 28), which owns ONLY the accept/reject arithmetic, burn-in and thinning; it draws from `rng` in the fixed order proposal-then-acceptance, so its output is bit-identical to the pre-0.2 hand-written loop (frozen 5×2 / 5×3 literals in the "MH kernel" testset), and it adds 0 bytes per step. `_mh_run!(rng, net, terms, θ, n_samples, burnin, interval, collect_networks, toggleable=:free)` is the binary-network adapter (the directedness is the network's type parameter `D`; there is no separate `directed` argument): it builds ONE of three proposal closures — `:free` (uniformly random unmasked dyad, never a loop, `i < j` undirected; the default), `:all` (any dyad), `:masked` (uniform over the `missing_dyads` list) — and hands it to `_mh_run_with_proposal!` (change statistics via `change_stat_all!` + `has_edge`, toggle + running statistics, sample write). `mh_sample(model, θ; ..., toggleable=:free)` is the public single-chain primitive (returns `(stats, networks)`; used by ERGMEgo.jl); `_check_toggleable` validates the set (`:masked` needs a mask; `:all`/`:masked` refuse a `missing=` opt-in as meaningless). The variants should adopt the kernel with their own moves (docstring sketches, fenced ```jl because they are not standalone programs). `sample_networks`/`simulate_ergm` split draws over `n_chains` independent chains via `Threads.@spawn`, each seeded deterministically from the caller's `rng` (`n_chains` must never default to `Threads.nthreads()`); `_random_network(net; density, rng, randomize_masked=false)` builds their starting states (masked dyads keep their face value unless `randomize_masked`). **Sampler defaults are ONE rule** (item 24e): `burnin`/`interval` are `nothing` on every entry point, resolved by `_resolve_mcmc_controls(model, burnin, interval; toggleable)` → `_mcmc_defaults(_n_toggleable(net, toggleable)) = (burnin = 20 * n, interval = max(100, n ÷ 10))` (`public`); never put a literal budget back on an entry point.

**Diagnostics** (`src/mcmc/diagnostics.jl`): `gof()` compares observed degree/ESP/geodesic distributions against simulated networks (accepts `rng`, `n_chains`, `burnin`, `interval`, `missing`). **The distance panel is R's `obs.dist`** (round 3): unordered pairs on an undirected network, ordered pairs (out-distances) on a directed one, one level per finite distance up to the largest seen and a final `"Inf"` level for unreachable pairs — pinned to R at 1e-9 on flomarriage (`[20, 35, 32, 15, 3, …, Inf 15]`) and samplike, together with R's `obs.deg`/`obs.esp`; the Julia testsets zero-pad the trimmed finite levels to R's length. `mcmc_diagnostics()` returns the exported **`MCMCDiagnostics`** struct (fields `term_names`, `autocorrelation`, `effective_sample_size`, `ess_geyer`, `geweke_z`, `geweke_p`, `n_samples`, `chain_lengths`; `show` prints one row per term) computed **chain by chain** from `ERGMResult.chain_lengths` (per-chain lag-1 AC length-weighted, both ESSs summed — the Geyer column IS `_effective_sample_size`'s estimator, so its minimum equals `fit.mcmc_convergence.n_eff` — Geweke z of the chain with the largest |z|); it throws `ArgumentError` on fits without MCMC samples. The Geyer machinery lives here: `_geyer_var`, `_geyer_ess`, `_geweke_z`, and `_mc_cov_of_mean(samples, chain_lengths)`.

**Precompilation** (`src/ERGM.jl`, PrecompileTools): the `@setup_workload` builds a 7-vertex undirected and a 6-vertex directed network with a `:grp` attribute inline (no dataset I/O) and the `@compile_workload` runs, for BOTH directedness type parameters, `fit_ergm(net, [Edges(), NodeMatch(:grp), GWESP(0.5)])`, `coeftable`/`confint`/`show`, an `edges + gwesp` `mcmle` (one iteration, one bridge rung, and a `bridge_rungs=0, n_chains=2` one), `mcmc_diagnostics`, `gof` and `simulate_ergm`, under a `ConsoleLogger(devnull, Warn)`. Measured 2026-09-09 (fresh process, warm depot): `using ERGM` 1.1 → 1.2 s; first MPLE 0.40 → 0.01 s for the workload's formula; first `mcmle` ≈1.1 → 1.5 s (Base logging/Printf on the warning path); precompilation ≈22 s. Keep it small and deterministic; anything it logs must be silenced.

**Entry point**: `fit_ergm(net, terms; method=:mple, kwargs...)` (bottom of `mple.jl`) and `const ergm = fit_ergm` (both documented, both exported). ## Key Dependencies

- **Networks.jl** - the ecosystem foundation: the `Network{T,D}` data structure with vertex/edge attributes and the missing-dyad mask (`set_missing_dyad!`, `missing_dyads`, `n_missing_dyads`), the missing-data, conversion and tied-event contracts, and the shared numerics ERGM imports by name (`newton_fit`, `logistic_derivatives`, `z_pvalues`, `check_se`, `bootstrap_cov`, `print_coeftable`/`CoefficientTable`, `mc_pvalue`, `load_golden`); resolved via `[sources]` from `../Networks.jl` (not in General)
- **Graphs.jl** - graph algorithms; `Network` wraps a `Graphs` graph internally (accessed via `net.graph` for things like `gdistances`)
- **Distributions.jl** - `Normal`/`Chisq`/`FDist` quantiles and tails for `confint`, the Hummel step control and the Hotelling convergence test (p-values themselves go through `Networks.z_pvalues`)
- **StatsAPI.jl** - the generics of the StatsAPI surface (`coef` … `coeftable`), each given a method on `ERGMResult`
- **PrecompileTools.jl** - the `@compile_workload` at the end of `src/ERGM.jl`
- **Printf** (stdlib) - `@sprintf("%.3g")` in `_fmt3`, the three-significant-digit formatter of every MCMLE/bridge diagnostic (a rounded Float64's `string` printed `6.969999999999999e-32`)

No optimizer package is a dependency: the MPLE runs on Networks' Newton kernel. StatsBase and SparseArrays are NOT dependencies either (nothing in `src` used them; StatsBase stays a test extra for the `using ERGM, StatsBase` co-loading check).

## Conventions

- All term statistics return `Float64`.
- `change_stat` returns the state-independent add-direction change statistic `g(y⁺ij) − g(y⁻ij)`. It must NOT depend on whether the edge currently exists; the MH sampler negates it for removal proposals.
- Term `name()` functions use R ergm-style lowercase names (e.g., `"edges"`, `"nodematch.gender"`, `"gwesp.fixed.0.5"`, `"gwdeg.fixed.1"`); fixed decays print through `_decay_label` exactly as R prints them.
- Internal/private functions are prefixed with underscore; mutators end in `!`; statnet-mirroring functions are snake_case.
- All randomness flows through `rng::AbstractRNG` keywords (default `Random.default_rng()`); never call bare `rand()` in sampling/fitting code. Parallel loops draw one seed per task from the caller's rng.
- Every behavioural change gets a `CHANGELOG.md` `[0.2.0] - Unreleased` entry in the right section.
- Every export (and `public` name) has a docstring with a runnable, self-contained ```julia example; the suite executes them.
